# Xlab Bot — downloads

This repository holds **nothing but the installers** for Xlab Bot. The source code lives in a
private repository; there is nothing to clone here.

## Get the latest version

Open **[Releases](../../releases)** and download `XlabBot-Setup-<version>.exe` from the newest
one.

Windows SmartScreen will say *"Windows protected your PC"* because the installer is not signed
with a commercial certificate. Click **More info** → **Run anyway**.

## You need a licence key

Xlab Bot does not run without one. On first launch it shows a licence screen with your
computer's **machine ID** — send that to **Hafiz Muhammad Ahsan** and paste back the key you
are given. A key is tied to the one computer it was issued for.

## Updates

Once installed, Xlab Bot checks here for new versions by itself: **Updates → Check now**, or it
tells you when one appears. You do not need to come back to this page.

## Requirements

- Windows 10 or 11
- Google Chrome (the bot drives it)
